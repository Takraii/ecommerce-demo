# E-commerce & Order Management Demo

เดโมร้านค้าและระบบจัดการคำสั่งซื้อแบบไฟล์เดียว เปิด `index.html` ผ่าน GitHub Pages ได้บนมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้ง framework หรือ server

## วิธีใช้งาน

1. เปิดหน้าเว็บ เลือก **ลูกค้า** เพื่อดูสินค้า ค้นหา เพิ่มตะกร้า และสร้างคำสั่งซื้อจำลอง
2. เลือก **หลังบ้าน** เพื่อจัดการสินค้าและคำสั่งซื้อ ยืนยันการชำระเงิน กำหนดจำนวนกล่อง ดูหรือพิมพ์ใบปะหน้า แล้วกด **ยืนยันพิมพ์เรียบร้อย**
3. ไปที่ **สแกนส่งมอบขนส่ง** สแกน Package ID แล้วสแกน Tracking Number สลับกันทีละกล่อง เครื่องสแกนแบบ keyboard wedge ใช้ Enter หลังแต่ละรหัสได้ บนมือถือใช้ปุ่ม **จำลองการสแกน**
4. เมื่อจับคู่ครบ กด **ยืนยันส่งมอบทั้งหมด** ครั้งเดียว ลูกค้าตรวจสถานะด้วยเบอร์โทรศัพท์ในหน้าตรวจสอบคำสั่งซื้อ

นี่เป็นเดโมเท่านั้น ไม่มีการชำระเงินจริงหรือการเชื่อมต่อบริษัทขนส่ง ข้อมูลสินค้า คำสั่งซื้อ และภาพที่อัปโหลดเก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ข้อมูลไม่ซิงก์ข้ามอุปกรณ์ และการล้างข้อมูลเว็บไซต์หรือกดรีเซ็ตจะลบการเปลี่ยนแปลงในเครื่องนั้น อย่าใส่ข้อมูลลูกค้าจริง

## เผยแพร่

GitHub Pages: Settings → Pages → **Deploy from a branch** → `main` → `/ (root)` เว็บจะเผยแพร่ผ่าน HTTPS ที่ `https://<username>.github.io/ecommerce-demo/`
